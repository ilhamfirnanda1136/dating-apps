# Flutter — Klik

Aplikasi kencan Material 3 (putih–pink) untuk Android, iOS, dan **Chrome**. Dokumentasi lengkap ada di [README akar repo](../README.md).

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:3000/api/v1
```

Login demo: `budi@mail.com` / `password123` (backend + seeder harus sudah jalan).

Setelah mengubah banyak file, tekan **R** di terminal `flutter run` (hot restart).

Komentar `///` di `lib/` memakai bahasa Indonesia untuk belajar Flutter: mulai dari `lib/main.dart`.
